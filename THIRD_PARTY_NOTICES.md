# Third-party notices

What each release file contains, under which licence, and where the source
is. The source of every release is the `master` commit tagged with its
version at https://github.com/esbon125/tandem.

| Release file | Contents | Licences |
|---|---|---|
| `mpeg2fpga-bitstream-*.job` | FPGA design: mpeg2fpga decoder core, own integration RTL, Discovery Kit reference design, Microchip IP generated by Libero SoC | BSD (core), CERN-OHL-S-2.0 (own RTL), MIT (reference design), Microchip licence terms (generated IP) |
| `mpeg2fpga-board-*.tar.gz` | Kernel driver `mpeg2fpga.ko` and its install scripts | GPL-2.0 |
| | `mpeg2fpgad` service and native converter | MIT |
| `mpeg2fpga-*.whl`, `mpeg2fpga-*.tar.gz` (Python) | Client library, standard library only | MIT |
| `mpeg2fpga-user-guide-*.pdf`, `PROTOCOL-v1.md` | Documentation | MIT |
| `mpeg2fpga-reference-manual-*.tar.gz` | Reference Manual, generated by Doxygen from the sources above; includes Doxygen's page scripts (jQuery and others, MIT) | Those of the documented sources; MIT (scripts) |

No release file includes the Linux image of the board; it comes from
Microchip's Discovery Kit reference design.

## CERN-OHL-S-2.0 (own RTL in the bitstream)

The bitstream is a product made from Covered Source under the CERN Open
Hardware Licence Version 2 - Strongly Reciprocal. Its Complete Source is the
tagged `master` commit (`trunk/mpeg2fpga/rtl/`, `trunk/mpeg2fpga/soc_build/`).
Licence text: `trunk/mpeg2fpga/rtl/LICENSE-CERN-OHL-S-2.0`.

## GPL-2.0 (kernel driver)

The corresponding source of `mpeg2fpga.ko` is `driver/mpeg2fpga/` at the
tagged `master` commit. Licence text:
https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt

## Microchip IP generated by Libero SoC

The MSS, clock conditioning circuit and other cores generated by Libero SoC
are distributed only as part of the bitstream, under Microchip's licence
terms for its IP and Libero-generated output.

## MPEG-2 patents

The core carries the original MPEG LA notice (`trunk/mpeg2fpga/rtl/LICENSE-MPEG2`).
The MPEG-2 video patents of the MPEG LA pool have expired in nearly every
country, the last United States one in February 2018.
