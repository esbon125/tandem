Estructura del directorio:

    docs| :documentación del proyecto
        |-anteproyecto: carpeta donde se halla la documentación del anteproyecto
        |-polarfire : documentos referidos a la placa utilizada
        |-propuesta : resumen de la idea sugerida para el proyecto
        |-org: documentos de planificación, asignación de recursos, etc.
